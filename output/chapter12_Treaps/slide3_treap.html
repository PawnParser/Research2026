(Trees + Heaps)Treaps

A treap (tree + heap) is a binary tree in which each node holds both a value (satisfying the BST ordering property) and a priority (satisfying the min-heap property). This combination keeps the tree balanced on average without requiring the explicit rotations of an AVL or red-black tree.
